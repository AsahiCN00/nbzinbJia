# nbzinbJia: NB and ZINB regression via IRLS and EM

Fits negative binomial regression
([`nbreg()`](https://asahicn00.github.io/nbzinbJia/reference/nbreg.md))
by IRLS alternated with Newton-Raphson for the dispersion parameter, and
zero-inflated negative binomial regression by an EM algorithm whose
M-steps are IRLS fits. No general-purpose optimizer is used.
